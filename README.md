- **Home Dashboard** — self-hosted, FastAPI + SQLite + WebSockets, served via Caddy in Docker
- **Photo Culling App** — FastAPI + vanilla JS + SQLite tool for sorting photography keepers, keyboard-driven workflow
- **Multiplayer Tag Game** — 3D tag game in Godot 4 (GDScript), host-authoritative netcode via ENetMultiplayerPeer
- **Print Progress Display** — ESP32 e-paper display showing live 3D printer progress from Home Assistant
